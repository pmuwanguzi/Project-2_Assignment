# Project-2_Assignment
This repo contains three projects in one, you will identify the source code with the matching compiled code by the project number.

to compile any of the project files use the following format:

gcc project_number.c -o project_number_project_name

to Run the compiled program please use the following.

./project_number_project_name

this should get the program running by displaying a menu on your terminal screen. 

*Enjoy
